# gm-ytdlp-helper
> Assist download Bilibili YouTube via yt‑dlp command.

## steps
1. 安装 [tampermonkey](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo?hl=en-US)
2. 打开 `tampermokey` 的管理面板(Dashboard)
3. 实用工具(tools)
4. Install from URL:
5. 用这个： https://raw.githubusercontent.com/afeiship/gm-ytdlp-helper/master/dist/install.js
